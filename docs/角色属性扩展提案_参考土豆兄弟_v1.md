# 角色属性扩展提案（参考《土豆兄弟》）

> 项目：TeleTarot-New  
> 日期：2026-04-21  
> 目标：在现有 `max_hp / move_speed / base_target_range / attack_damage` 基础上，补充可构筑、可取舍、可成长的角色属性。

## 1. 设计目标

- 让每次升级不只是“变强”，而是“选方向”。
- 引入正负权衡（高输出通常伴随生存代价）。
- 保持低数值体系可读性，不把战斗变成复杂算表。
- 与当前代码结构兼容（`player.gd` + `combat_balance.json` + `upgrade_system.gd`）。

## 2. 建议新增属性（首批）

| 属性 | 英文键名建议 | 作用 | 建议上限/下限 | 参考定位 |
|---|---|---|---|---|
| 护甲 | `armor` | 降低受到伤害 | 建议 `-10 ~ 30` | 生存核心 |
| 闪避率 | `dodge_chance` | 概率完全免伤 | 建议硬上限 `60%` | 高风险角色核心 |
| 攻速倍率 | `attack_speed_mult` | 缩短自动攻击间隔 | 建议软上限 `2.5x` | 输出与手感核心 |
| 暴击率 | `crit_chance` | 触发暴击概率 | 建议上限 `75%` | 爆发型构筑 |
| 暴击伤害 | `crit_multiplier` | 暴击时伤害倍率 | 建议 `1.5x~3.0x` | 与暴击率联动 |
| 吸血 | `lifesteal` | 造成伤害后回血 | 建议上限 `25%` | 持续作战 |
| 幸运 | `luck` | 提升掉落质量/高稀有奖励概率 | 建议 `-20~100` | 经济与成长 |
| 经验增益 | `xp_gain_mult` | 提升经验获取效率 | 建议上限 `+80%` | 成长节奏控制 |

## 3. 计算口径建议（简化且稳定）

### 3.1 护甲减伤

- 推荐公式：`final_damage = ceil(raw_damage * 100 / (100 + armor * 8))`
- 当 `armor < 0` 时自然变成增伤，形成“玻璃炮”代价。

### 3.2 闪避

- 在最终受击前判定：
- `if randf() < dodge_chance: damage = 0`
- 强制硬上限 `60%`，避免后期完全无敌。

### 3.3 攻速

- 当前有 `auto_attack_interval`，建议改为：
- `real_interval = base_interval / attack_speed_mult`
- `attack_speed_mult` 最低不低于 `0.3`，防止“攻速负增长崩盘”。

### 3.4 暴击

- 暴击判定：`if randf() < crit_chance`
- 暴击伤害：`damage = floor(base_damage * crit_multiplier)`

### 3.5 吸血

- 推荐以“命中后结算”：
- `heal = max(1, floor(final_damage * lifesteal))`（再做每秒或每次命中上限）
- 建议增加“每 0.1s 最多触发 1 次”防止多段弹幕吸血过强。

### 3.6 幸运与经验增益

- 幸运影响：高品质奖励权重、金币掉落浮动、补给站高阶词条出现率。
- 经验增益影响：`xp_final = floor(xp_raw * xp_gain_mult)`。

## 4. 首批落地优先级（建议）

1. 护甲（`armor`）
2. 闪避率（`dodge_chance`）
3. 攻速倍率（`attack_speed_mult`）
4. 暴击率+暴击伤害（`crit_chance` + `crit_multiplier`）
5. 吸血（`lifesteal`）

说明：这 5 组最接近《土豆兄弟》的核心构筑体验，且对当前战斗循环改动最小。

## 5. 与现有三角色的方向建议

| 角色 | 建议偏向 | 不建议方向 |
|---|---|---|
| 愚者 The Fool | `attack_speed_mult`、`dodge_chance`、`luck` | 纯堆护甲（风格不符） |
| 战车 The Chariot | `armor`、`crit_multiplier`、中等 `lifesteal` | 极限闪避流 |
| 倒吊人 The Hanged Man | `lifesteal`、`crit_chance`、负护甲换输出 | 过高上限闪避（易失控） |

## 6. 数据层建议（可直接加到 JSON）

建议在角色初值中补齐字段：

```json
{
  "armor": 0,
  "dodge_chance": 0.00,
  "attack_speed_mult": 1.00,
  "crit_chance": 0.05,
  "crit_multiplier": 1.50,
  "lifesteal": 0.00,
  "luck": 0,
  "xp_gain_mult": 1.00
}
```

并在奖励池新增对应词条：

- `+2 armor`
- `+8% dodge_chance`
- `+12% attack_speed_mult`
- `+10% crit_chance`
- `+25% crit_multiplier`
- `+4% lifesteal`
- `+8 luck`
- `+15% xp_gain_mult`

## 7. 平衡建议（避免数值爆炸）

- 所有概率类属性加硬上限（闪避、暴击）。
- 生存与输出词条在同一次奖励中尽量二选一。
- 吸血、闪避、护甲同时堆高时，给出边际递减或软上限。
- 每个角色至少保留 1 个“短板属性”，确保构筑差异成立。

## 8. 版本推进建议

1. `v1`：只上 `armor / dodge / attack_speed / crit / lifesteal`。
2. `v2`：加入 `luck / xp_gain_mult`，再调奖励池。
3. `v3`：基于通关数据做 cap 微调（尤其闪避和吸血）。
