# 补给站地图提示词_v1
> 版本：v1.0  
> 日期：2026-04-15  
> 适用：`Supply Hub` 场景地图绘制 / 文生图出图 / 外包美术说明  
> 关联：`产品基线_v1.3`、`UI与视觉风格规范`

## 1. 目标风格
- 类型：2D 俯视角（top-down）像素风补给站
- 氛围：梦核 + 故障感 + 轻度 CRT 时代感
- 关键词：`dark teal`, `retro terminal`, `mysterious ritual hub`, `pixel-art`, `clean readable gameplay floor`
- 设计重点：可读性优先，地图服务交互，不做复杂障碍物迷宫

## 2. 主提示词（通用底稿）
```text
Top-down 2D pixel-art supply hub map for an action roguelite, dark teal and navy palette, dreamcore glitch atmosphere, subtle ritual symbols, clean walkable floor, soft vignette mood, old CRT era sci-fi fantasy tone, high readability gameplay space, clear center area for player movement, four vendor spots around center, minimal clutter, no combat hazards, no text, no logo, no UI elements, game-ready tileable background feel
```

## 3. 结构提示词（按当前玩法）
```text
Layout: compact rectangular hub, one central open zone for player, four vendor anchors around center (upper-left witch, upper-center seer, lower-center broker, lower-right traveler), each anchor has a subtle visual marker, traversable paths between all anchors, no dead-end maze, no blocking walls in center, decorative edges only
```

## 4. 负面提示词（必须带）
```text
no side view, no isometric perspective, no realistic photo style, no heavy bloom, no over-sharpened edges, no dense props blocking movement, no UI frame, no text label, no watermark, no logo, no signature, no high-frequency noisy background, no extreme contrast flicker
```

## 5. 出图参数建议
- 分辨率建议：`1920x1080`（场景稿）或 `1536x1024`（中间稿）
- 像素风建议：先出高清草图，再做像素化整理，避免直接低清导致脏边
- 色彩控制：背景明度低于角色 20% 以上，确保 NPC 与玩家可读
- 边缘质量：避免强锐化，优先柔和过渡，后续由引擎统一 CRT 处理

## 6. 变体提示词（可选）
### A. 稳定商店版（推荐首稿）
```text
calm safe supply hub, clean floor readability, subtle mystic props, low visual noise, balanced negative space, gameplay-first composition
```

### B. 仪式感强化版

```text
ritual techno shrine hub, arcane circles and signal runes on floor edges, mysterious but clear center, controlled glitch motifs
```

### C. 终幕准备版（Boss前）
```text
late-chapter preparation hub, slightly tense atmosphere, deeper shadows, restrained warning accents, still fully readable gameplay space
```

## 7. 对接当前实现的落地约束
- 当前 Hub 为紧凑地图，活动区建议围绕中心，不要扩成大面积空场。
- 美术构图需预留四个商人位置（与现有交互点一致）：
  - Witch：左上区域
  - Seer：上中区域
  - Broker：下中区域
  - Traveler：右下区域
- 中央区域需保持大块可行走地面，保证按 `E` 交互时视线清晰。
- 地图背景不要自带文字，NPC 名称由游戏内 `Label` 显示。

## 8. 验收清单（交付给美术/外包）
- 俯视角正确，无侧视/等距偏移
- 中心可读、路径清晰、交互点明确
- 低噪声背景，不抢 UI 与角色
- 无文字/无水印/无 logo
- 导入 Godot 后在 CRT 叠层下仍清晰
