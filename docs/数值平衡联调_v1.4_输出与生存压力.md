# 数值平衡联调 v1.4（输出与生存压力）

## 1. 目标与口径（中度联调）
- 目标：在保留角色/武器差异的前提下，下调玩家中前期输出峰值，同时提升敌人追击与耐久压力。
- 范围：仅调整可配置数值与必要读取接线，不改战斗核心公式与存档结构。
- 预期：玩家有效输出（DPS）整体下降约 20%-30%，敌方压迫感提升但不突变。

## 4. 联动影响评估

### 4.1 TTK（击杀时间）
- 单把武器对同类敌人的 TTK 上升，预计区间约 +25% 至 +40%。
- 高爆发构筑出现时间后移，避免中前期“秒怪滚雪球”。

### 4.2 被追击压力
- 中期开始近战贴身频率增加，玩家需更频繁走位与换位。
- 远程/弹幕单位保留读条窗口，不做瞬时贴脸。

### 4.3 波次时长
- stage_001 体感略慢但仍可稳定清理。
- stage_002-003 清场速度下降，战斗决策密度提升。

## 5. 回归与验收指标
- 三把起始武器在同一目标上的 TTK 较旧版上升 25%-40%。
- 10 局 normal 中位生存时长落在 6-10 分钟。
- stage_002 前全通率目标 50%-70%，不出现开局卡死。
- 存读档后输出参数与敌方参数一致。
- weapon_select -> game -> shop -> next stage 全链路数值一致生效。

## 6. 实现说明
- 本次已接入 stage 级敌方 HP/移速乘区读取：
  - 最终敌人血量 = 敌人基础 max_hp * 难度敌方血量乘区 * stage 敌方血量乘区
  - 最终敌人移速 = 敌人基础 move_speed * stage 敌方移速乘区
- 未改动伤害结算公式、暴击逻辑与存档字段结构。
