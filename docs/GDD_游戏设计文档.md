## 1. 项目概述

### 1.1 游戏基本信息

| 属性         | 内容                                        |
| ------------ | ------------------------------------------- |
| **游戏类型** | 像素2D俯视角 / 肉鸽Roguelike / 弹幕射击     |
| **核心灵感** | 吸血鬼幸存者 (Vampire Survivors) + 梦核美学 |
| **目标平台** | PC (Windows)                                |
| **开发引擎** | Godot 4.6                                   |
| **视角**     | 俯视角度 (Top-down 2D)                      |
| **艺术风格** | 梦核/故障艺术 (Dreamcore/Glitch Art)        |

### 1.2 核心体验关键词

- **迷离** - 梦境般的不真实感
- **压抑** - 老式电子设备的窒息感
- **循环** - 无尽战斗的宿命感
- **异化** - 塔罗牌象征的哲学隐喻

### 1.3 一句话描述

> 在闪烁着雪花点的CRT屏幕中，操控塔罗牌化身，于无尽的梦境战场中求生、进化、直至觉醒。

## 2. 核心玩法循环

```
┌─────────────┐
│   主界面    │
│  (标题画面) │
└──────┬──────┘
	   │ 点击「开始游戏」
	   ▼
┌─────────────┐
│  角色选择   │ ←──┐
│ (愚者/战车/ │    │
│  倒吊人)    │    │
└──────┬──────┘    │
	   │           │
	   ▼           │
┌─────────────┐    │
│   战斗关卡  │    │
│ (自动攻击+  │    │
│  移动控制)  │    │
└──────┬──────┘    │
	   │           │
	   ▼           │
┌─────────────┐    │
│ 敌人全灭?   │──否─┘
│   是 ↓      │
└──────┬──────┘
	   ▼
┌─────────────┐
│   奖励选择  │
│ (三选一升级)│
└──────┬──────┘
	   │
	   ▼
┌─────────────┐
│  下一关推进 │ ──→ (章节Boss后进入补给站) ──→ 第15关后真最终Boss → 结算
└─────────────┘
```

### 2.1 战斗阶段详解

**操作方式：**

- **移动**: WASD / 方向键（8方向）
- **攻击**: 全自动（无需手动）
- **技能**: 空格键 / 鼠标右键（主动释放）

**核心机制：**

1. **自动攻击系统**
   - 角色自动向最近敌人发射弹幕
   - 攻击频率受属性影响
   - 可同时存在多个攻击源

2. **经验值与升级**
   - 击杀敌人掉落经验宝石
   - 拾取后积累经验值
   - 升级时暂停游戏，弹出奖励选择

3. **生存压力**
   - 敌人数量随时间递增
   - 敌人强度随波次提升
   - 限时清场增加紧迫感

### 2.2 主线关卡基线（v1.3）

- 教学关单独存在，不计入主线总关卡数。
- 主线固定为 **15关**，采用线性章节推进。
- 第 **5/10/15** 关为章节Boss关（共3个章节Boss）。
- 每次击败章节Boss后进入补给站：可进行**付费回复 / 道具购买 / 属性强化**。
- 通过第15关后，进入**真最终Boss**战（主线通关战）。

章节结构：

1. Chapter I：第1-5关（第5关 Boss-1）
2. Chapter II：第6-10关（第10关 Boss-2）
3. Chapter III：第11-15关（第15关 Boss-3）
4. Final：真最终Boss

## 3. 视觉风格规范

### 3.1 核心美学：梦核 + CRT故障艺术

#### CRT显示器效果（全局滤镜）

```godot
# 后处理效果清单
- [ ] 屏幕曲面变形 (Barrel Distortion)
- [ ] 扫描线 (Scanlines) - 水平细线纹理
- [ ] 色彩分离 (Chromatic Aberration) - RGB通道偏移
- [ ] 噪点干扰 (Noise/Film Grain) - 随机像素扰动
- [ ] 闪烁效果 (Flicker) - 亮度随机波动
- [ ] 垂直同步滚动 (V-Hold) - 偶发画面抖动
- [ ] 边缘暗角 (Vignette) - 四角压暗
- [ ] 像素化 (Pixelation) - 低分辨率渲染
```

#### 配色方案（暂定）

| 元素         | 颜色   | 色值      | 用途      |
| ------------ | ------ | --------- | --------- |
| **背景主色** | 深空蓝 | `#0a1628` | 战场背景  |
| **UI底色**   | 故障紫 | `#2d1b4e` | 面板背景  |
| **强调色**   | 信号绿 | `#00ff41` | 文字/高亮 |
| **警告色**   | 干扰红 | `#ff0040` | 危险/伤害 |
| **中性色**   | 静电灰 | `#8b9bb4` | 次要信息  |

### 3.2 UI设计原则

**字体选择：**

- 主标题：等宽像素字体（如 Press Start 2P / 像素风格中文字体）
- 正文：清晰的无衬线字体（带轻微模糊效果）
- 数字：七段数码管风格

**交互反馈：**

- 按钮：悬停时出现水平撕裂效果
- 选中项：RGB色彩快速切换的故障动画
- 确认：屏幕闪白 + 噪声爆发音效

**布局特征：**

- 不对称边框（模拟信号不良）
- 偶发的文字乱码（装饰性）
- 测试卡风格的元素（色块、几何图形）

### 4.2 核心系统模块

**GameManager（全局状态机）**

```
状态枚举: MENU -> CHARACTER_SELECT -> PLAYING -> REWARD -> STAGE_SELECT -> GAME_OVER
职责:
- 管理游戏流程转换
- 持久化玩家数据
- 处理场景切换
- 统计全局数据（总击杀数、游戏时长等）
```

**CombatSystem（战斗系统）**

```
核心功能:
- 自动瞄准最近目标
- 弹幕生成与回收池
- 伤害计算与判定
- 击退/硬直效果
```

**WaveManager（波次管理）**

```
流程:
1. 初始化当前波次敌人配置
2. 按时间间隔生成敌人
3. 监测存活敌人数量
4. 全灭后触发结算事件
5. 进入下一阶段
```

## 5. 音频设计方向

### 5.1 音乐风格

- **主菜单**: 低频嗡鸣 + 偶发的电子杂音（营造不安感）
- **战斗BGM**: Dark Ambient / Industrial Techno
- **Boss战**: 节奏加快，加入失真的合成器音色
- **结算**: 信号中断后的静默或纯音测试音

### 5.2 音效设计

- **攻击**: CRT放电声 / 数字失真爆裂声
- **受伤**: 静电干扰声
- **拾取**: 短促的高频正弦波
- **升级**: 信号校准声（类似老电视调台）
- **UI交互**: 机械键盘敲击声 + 轻微回声

## 8. 设计哲学

### 核心隐喻

本游戏不仅是娱乐产品，更是一件**互动艺术装置**：

- **塔罗牌** = 命运的碎片化呈现
- **CRT屏幕** = 意识的边界，现实与虚幻的接口
- **无尽战斗** = 存在主义式的西西弗斯神话
- **肉鸽机制** = 记忆的不确定性，每次都是"第一次"

### 玩家情感曲线

```
好奇 → 困惑 → 掌握 → 压抑 → 释放 → 异化 → 沉浸
```
