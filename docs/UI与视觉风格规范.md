## 1. 视觉风格总纲

### 1.1 核心美学定义

**风格名称**: **梦核故障艺术 (Dreamcore Glitch Aesthetics)**

**灵感来源**:

- 90年代 CRT 电视/显示器的物理特性
- 模拟信号干扰的视觉效果
- 梦境记忆的不稳定性和模糊感
- 老式电子设备的工业美学
- 测试卡 (Test Pattern) / 雪花屏 (Static Noise)
- VHS 录像带的追踪误差 (Tracking Error)

**情感目标**:
| 目标 | 描述 | 实现手段 |
|------|------|----------|
| **怀旧感** | 对旧技术的怀念 | CRT 曲面、扫描线、色温偏移 |
| **不安感** | 技术故障带来的紧张 | 随机闪烁、画面撕裂、噪点 |
| **沉浸感** | 进入梦境世界的入口 | 全屏滤镜、边缘暗角 |
| **独特性** | 与众不同的视觉标识 | 一致的故障艺术语言 |

### 1.2 视觉层次结构

```
┌─────────────────────────────────────┐
│         第0层: CRT全局滤镜           │ ← 最顶层后处理
│  (曲面变形 + 扫描线 + 噪点 + 暗角)    │
├─────────────────────────────────────┤
│         第1层: 游戏世界              │
│  (角色、敌人、弹幕、特效、背景)        │
├─────────────────────────────────────┤
│         第2层: UI界面                │
│  (HUD、菜单、面板、文字、图标)        │
└─────────────────────────────────────┘
```

## 2. CRT 显示器效果规范

### 2.1 效果参数配置

#### A. 屏幕曲面变形 (Barrel Distortion)

```godot
# CRTEffect.gd - 曲面参数
@export_group("屏幕曲面")
@export var barrel_distortion_amount: float = 0.05  # 变形强度 (0-0.15)
@export var barrel_distortion_radius: float = 0.8   # 有效区域半径
@export var vignette_strength: float = 0.4          # 边缘暗角强度

# 着色器实现思路:
# 使用 UV 坐标到中心的距离来偏移采样位置
# 距离越远，偏移越大，形成向内凹陷的视觉效果
```

**视觉参考**:

- 边缘约 10-15% 的区域有轻微向内弯曲
- 四角最明显，中心区域几乎无变形
- 模拟老式显像管的球面屏幕

#### B. 扫描线效果 (Scanlines)

```godot
@export_group("扫描线")
@export var scanline_opacity: float = 0.08      # 线条透明度 (0.03-0.15)
@export var scanline_spacing: float = 2.0       # 线条间距（像素）
@export var scanline_thickness: float = 1.0     # 线条粗细
@export var scanline_movement: bool = true       # 是否缓慢滚动 (模拟刷新)

# 实现方式:
# 使用 sin(uv.y * frequency + time * speed) 生成周期性明暗条纹
# 叠加到最终渲染结果上（混合模式：Multiply 或 Overlay）
```

**视觉参考**:

- 细微的水平线条纹理
- 不影响可读性的前提下增加复古质感
- 可选：轻微滚动模拟隔行扫描 (Interlacing)

#### C. 色彩分离/色差 (Chromatic Aberration)

```godot
@export_group("色彩分离")
@export var chromatic_aberration_amount: float = 0.003  # RGB偏移量
@export var aberration_dynamic: bool = true             # 动态变化
@export var aberration_speed: float = 2.0              # 波动频率

# 实现方式:
# R通道向左偏移, B通道向右偏移 (或随机方向)
# 偏移量随时间正弦波动，模拟信号不稳定
# 在高对比度边缘（如文字）效果最明显
```

**视觉参考**:

- 文字和物体边缘出现红蓝/青红边框
- 像是3D眼镜效果失败的样子
- 动态变化时营造"信号不良"的感觉

#### D. 噪点/颗粒 (Noise / Film Grain)

```godot
@export_group("噪点")
@export var noise_opacity: float = 0.04            # 噪点强度
@export var noise_type: int = 0                    # 0=高斯, 1=均匀, 2=像素化
@export var noise_animation_speed: float = 10.0    # 噪点变化速度
@export var colored_noise: bool = false            # 彩色噪点(默认灰度)

# 实现方式:
# 基于伪随机函数生成逐帧变化的噪声纹理
# 使用 ScreenUV + Time 作为种子确保每帧不同
# 低强度叠加，避免过于干扰视线
```

**视觉参考**:

- 类似老电视的雪花点
- 细微的颗粒质感
- 增加画面的"不纯净"感

#### E. 其他可选效果

```godot
@export_group("附加效果")
@export var flicker_enabled: bool = true
@export var flicker_intensity: float = 0.02       # 亮度波动幅度
@export var flicker_threshold: float = 0.98       # 触发概率(每帧)
@export var vhold_jitter: bool = true             # 垂直抖动(偶发)
@export var vhold_intensity: float = 3.0          # 抖动像素数
@export var phosphor_glow: bool = false           # 荧光粉余辉(高级)
@export var ghosting_frames: int = 0              # 残影帧数(性能消耗大)
```

### 2.2 CRT 效果优先级

**MVP阶段（必须实现）**:

- ✅ 屏幕曲面变形
- ✅ 扫描线
- ✅ 边缘暗角

**Phase 2（增强体验）**:

- ⬜ 色彩分离
- ⬜ 闪烁效果

**Phase 3（锦上添花）**:

- ⬜ 荧光余辉

## 4. UI 组件设计规范

### 4.1 通用原则

**尺寸基准**:

- 设计分辨率: **1920 × 1080** (16:9)
- UI缩放基准: 以高度1080为参考
- 安全区域: 距离边缘至少 40px（考虑CRT曲面裁切）

**字体层级**:

| 用途         | 字体建议      | 大小    | 字重     | 颜色      |
| ------------ | ------------- | ------- | -------- | --------- |
| **主标题**   | 像素字体/等宽 | 48-64px | Bold     | `#00ff41` |
| **副标题**   | 无衬线        | 28-32px | SemiBold | `#e0e6ed` |
| **正文**     | 无衬线        | 18-20px | Regular  | `#e0e6ed` |
| **辅助文字** | 无衬线        | 14-16px | Light    | `#8b9bb4` |
| **数据数字** | 等宽/数码管   | 24-36px | Medium   | `#00ffff` |

**间距系统**:

```css
--space-xs: 4px;
--space-sm: 8px;
--space-md: 16px;
--space-lg: 24px;
--space-xl: 32px;
--space-xxl: 48px;
```

## 6. 动画与过渡规范

### 6.1 界面转场

| 转场类型     | 时长 | 效果描述                          |
| ------------ | ---- | --------------------------------- |
| **场景切换** | 0.5s | CRT关机→开机效果（收缩为点→展开） |
| **弹窗出现** | 0.3s | 从中心缩放 + 轻微弹性             |
| **弹窗消失** | 0.2s | 缩小至消失 + 淡出                 |
| **页面滑动** | 0.4s | 水平滑动（带水平撕裂痕迹）        |

### 6.2 交互动画

| 交互动作     | 动画反馈                                  |
| ------------ | ----------------------------------------- |
| **按钮悬停** | 边框颜色变化 + 轻微放大(1.05x) + 故障抖动 |
| **按钮点击** | 缩小(0.95x) → 弹回 + 屏幕闪白             |
| **物品拾取** | 飞向UI对应位置 + 数字飘字(+10 XP)         |
| **受到伤害** | 屏幕边缘红色闪框 + 角色闪烁               |
| **升级提示** | 文字从下方滑入 + 放大 + 金光              |
| **敌人死亡** | 像化消散（分解为小方块飞散）              |

### 6.3 特殊动画库

**故障效果 (Glitch Effect)**:

```godot
# 用于重要UI元素的装饰性动画
func apply_glitch_effect(node: Node, intensity: float = 1.0):
	# 水平位移抖动
	node.position.x += randf_range(-2, 2) * intensity
	# RGB分离
	modulate_shader("chromatic_aberration", intensity * 0.01)
	# 随机切片偏移
	if randf() < 0.1 * intensity:
		slice_horizontal(node, randi() % 5, randf_range(-5, 5))

# 触发时机:
# - 悬停在关键按钮上
# - 受到伤害时
# - 系统消息出现时
# - 随机间隔（保持不安感）
```

## 7. 可访问性与性能考虑

### 7.1 可访问性

**色盲友好**:

- 不仅依赖颜色传达信息，同时使用图标/形状/文字
- 重要状态变化配合动画反馈（不仅是颜色变化）
- 提供高对比度模式选项

**文字可读性**:

- 最小字号不低于 14px
- 文字与背景对比度 ≥ 4.5:1 (WCAG AA标准)
- 避免在复杂背景上直接放置文字（使用文字阴影/描边）

**操作适配**:

- 所有功能可通过键盘完成（无需鼠标）
- 支持自定义按键绑定
- 提供「简化UI」模式（减少视觉干扰）

### 7.2 性能预算

| 资源类型         | 预算              | 说明                          |
| ---------------- | ----------------- | ----------------------------- |
| **UI纹理集**     | < 2048×2048 合图  | 使用TextureAtlas减少DrawCall  |
| **字体文件**     | < 2MB each        | 使用动态字体 + 预渲染常用字符 |
| **着色器复杂度** | < 50 instructions | CRT效果需优化                 |
| **UI帧率**       | 独立于游戏帧率    | UI使用固定时间步进            |
| **内存占用**     | < 50MB for UI     | 及时释放未使用的UI资源        |
