# 📌 产品基线（Source of Truth）v1.3

## 1. 主线结构

- 教学关：独立存在，不计入主线总关卡数。
- 主线：15关（线性推进）。
- 章节Boss：第5关 / 第10关 / 第15关。
- 真最终Boss：第15关后解锁，作为主线终局战。

## 2. 章节划分

1. Chapter I：第1-5关（第5关 Boss-1）
2. Chapter II：第6-10关（第10关 Boss-2）
3. Chapter III：第11-15关（第15关 Boss-3）
4. Final：真最终Boss战

## 3. 补给站规则

- 触发时机：击败第5/10/15关章节Boss后。
- 核心功能：
  - 付费状态回复（HP恢复与异常清除）
  - 道具购买（常驻增益/消耗型）
  - 属性强化（递增价格与上限）
- 第15关后补给站视为“终幕准备”，离开后进入真最终Boss入口。

## 4. 货币用途基线

- 当前版本金币主要用于补给站消费闭环。
- 局外永久成长不计入当前主线平衡模型。

## 5. 角色解锁口径

- 愚者：教学关完成后可用。
- 战车：通关第5关后解锁。
- 倒吊人：通关第10关后解锁。

## 6. 输入口径（当前）

- 移动：WASD / 方向键
- 主动技能：空格键 / 鼠标右键
- 普攻：自动

- 版本：v1.3
