# 土豆兄弟角色经验成长模型

> 项目：TeleTarot-New（参考研究）  
> 日期：2026-04-22  
> 说明：本文件总结《土豆兄弟》角色经验成长的“数学模型”，用于机制借鉴，不用于内容复刻。

---

## 1. 经验成长主公式

土豆兄弟的等级需求是二次增长：

```text
XP_need(target_level) = (target_level + 3)^2
```

其中 `target_level` 为“升级后的目标等级”。
等价写法（更常用于程序）：

```text
XP_need_from_current(current_level) = (current_level + 4)^2
```

示例：

- 0 -> 1：`(0+4)^2 = 16`
- 1 -> 2：`(1+4)^2 = 25`
- 2 -> 3：`(2+4)^2 = 36`
- …

按 Wiki 表格口径（常见玩家阅读口径）：

```text
第 N 次升级需求 ≈ (N+3)^2
```

关键特征：

- 单级成本随等级线性变大；
- 累计成本随等级立方增长（因为是平方项求和）。

---

## 2. 累计经验模型（总成本）

到达等级 `L` 的累计经验（从 0 级起算）可写为：

```text
XP_total(L) = Σ(i=0..L-1) (i+4)^2
            = ((L+3)(L+4)(2L+7))/6 - 14
```

用途：

- 估算一局内目标等级（例如 20 波结束平均能到几级）；
- 反推需要多少经验增益才多拿 1~2 次升级。

---

## 3. 经验来源与结算

经验主要来自：

1. 敌人掉落材料拾取（材料=金币+经验等值）  
2. Harvesting（每波结算给材料，也包含等值经验）  
3. 少量角色/道具特效（间接增益）

统一结算口径可抽象为：

```text
XP_gained = (XP_from_drops + XP_from_harvesting + XP_from_other) * XP_Gain_Mult
```

其中：

- `XP_Gain_Mult` 由角色词条、道具词条叠加得到；
- XP 增益作用于“所有经验来源”，不是只作用于击杀。

---

## 4. 角色经验修正模型

角色主要通过两种方式改变成长节奏：

### 4.1 改“获取倍率”

```text
XP_Gain_Mult = 1 + Σ(xp_gain_bonus) - Σ(xp_gain_penalty)
```

例：`+25% XP Gain` => 乘 `1.25`。

### 4.2 改“升级成本倍率”

```text
XP_need_effective(level) = XP_need_base(level) * XP_Cost_Mult
```

典型口径：

- `+130% XP required` => `XP_Cost_Mult = 2.30`
- `+200% XP required` => `XP_Cost_Mult = 3.00`
- `-66% XP required` => `XP_Cost_Mult = 0.34`

最终可合并为“有效成长速度”近似：

```text
Growth_Efficiency ≈ XP_Gain_Mult / XP_Cost_Mult
```

---

## 5. 升级收益模型

每次升级的核心收益：

- 获得固定基础收益（如 +1 Max HP，按版本口径）
- 获得一次升级选项（构筑方向选择）

因此等级价值并非只来自“数值点”，而是：

```text
Level_Value = 基础面板收益 + 构筑选择权收益
```

这也是 XP 在构筑游戏中高价值的根本原因。

---

## 6. 为什么 XP 增益有“边际递减感”

虽然 XP 增益是线性乘法，但升级需求是平方增长：

- 前期 20% XP 增益可能很快多拿 1 级；
- 后期同样 20% 往往只推进半级左右。

因此体验上会出现：

- 前期收益显著；
- 后期边际变弱。

这不是增益失效，而是被成本曲线吃掉。

---

## 7. 可迁移到 TeleTarot 的参数化模板

如果你要在项目里复用“同结构，不同数值”：

```text
XP_need(level) = (level + A)^B
XP_gained = XP_raw * XP_Gain_Mult
XP_need_effective = XP_need * XP_Cost_Mult
```

推荐初始参数：

- `A = 3~5`
- `B = 1.8~2.2`

调参抓手：

- 想让前期更快：减小 `A` 或提高基础掉落；
- 想让中后期更有压力：提高 `B`；
- 想让特定角色成长更快：提高 `XP_Gain_Mult` 或降低 `XP_Cost_Mult`。

---

## 8. 快速结论

土豆兄弟的经验成长模型本质是：

- 二次成本曲线控制升级速度；
- 全来源乘法增益提升成长效率；
- 角色通过“增益倍率 / 成本倍率”塑造强烈成长差异；
- 升级价值由“数值 + 构筑选择权”共同决定。
