# 土豆兄弟数值成长曲线与数值模型总结

> 项目：TeleTarot-New  
> 日期：2026-04-22  
> 目的：提炼《土豆兄弟》（Brotato）在 20 波标准流程中的成长曲线与核心数值模型，作为本项目平衡设计参考。

---

## 1. 一句话结论

《土豆兄弟》的核心并不是“线性变强”，而是把 **玩家成长、敌方成长、经济衰减、商店通胀** 四条曲线叠在一起：

- 玩家强度主要靠等级与商店购买增长（前中期偏快）。
- 敌方压力（HP/伤害）按波次持续上升，并在精英/首领波产生离散跳点。
- 经济端存在天然刹车（材料掉率衰减 + 价格通胀），防止无限滚雪球。
- 因此整体体验是：`前期建立优势 -> 中期做取舍 -> 后期做生存检定`。

---

## 2. 成长曲线（按波次阶段）

### 2.1 早期（Wave 1-6）：构筑起步期

- 波次时长从 20s 增长到 45s，资源回收节奏逐步拉长。
- 材料掉落率在 Wave 5 才开始衰减，前 4 波经济相对宽松。
- 商店仍以低稀有为主，目标是快速补齐武器组与基础生存词条。

设计含义：让玩家尽快形成“可运行 Build”，而不是立刻进入生存压力。

### 2.2 中期（Wave 7-14）：分流与锁定期

- 掉率持续下降、价格持续上涨，经济开始明显紧张。
- 稀有度概率提升，开始出现“高质量但昂贵”的选择。
- 在 Danger 2+ 可能进入精英/尸潮波，检验机动与容错。

设计含义：中期不是纯增伤，而是明确路线（输出、经济、生存三者取舍）。

### 2.3 后期（Wave 15-20）：生存检定期

- 常规波压力高，精英/Boss 波带来离散难度峰值。
- Wave 20 为终局 Boss 波（90s），要求 Build 同时具备输出与续航。
- 如果前中期只堆单一维度，后期容易在容错或清场效率上崩盘。

设计含义：终盘考核的是“综合体质”，不是单项极值。

## 3. 核心数值模型（可复用）

以下模型是对 Brotato 机制的抽象，便于在 TeleTarot 中做参数化实现。

### 3.1 输出模型（Player DPS）

对单件武器 i：

```text
DPS_i ~= HitDamage_i * HitRate_i * ExpectedHits_i * Uptime_i
ExpectedCritFactor_i = 1 + CritChance_i * (CritMult_i - 1)
HitDamage_i ~= (BaseDamage_i + MainStatScale_i) * DamageMult * ExpectedCritFactor_i
HitRate_i ~= 1 / EffectiveCooldown_i
```

总输出：

```text
TotalDPS ~= sum(DPS_i), i in [1..weapon_slots]
```

要点：

- 攻速对不同武器收益不一致（存在最小攻速与边际递减）。
- 多段命中、穿透、弹射会放大“每发伤害”的实际收益。
- 暴击收益依赖武器原生暴击倍率，不是全武器等价。

### 3.2 生存模型（EHP）

护甲对“伤害承受比例”的核心口径：

```text
if armor >= 0:
  damage_received_ratio = 1 / (1 + armor / 15)
else:
  damage_received_ratio = (15 - 2*armor) / (15 - armor)
```

期望受击伤害（含闪避）：

```text
ExpectedDamageTaken ~= RawIncoming * damage_received_ratio * (1 - dodge)
```

等效生命（EHP）近似：

```text
EHP ~= HP / (damage_received_ratio * (1 - dodge))
```

要点：

- 护甲“减伤百分比”看似递减，但 **EHP 近似线性抬升**（每点护甲约 +6.67% EHP）。
- 闪避有硬上限（通常 60%），是概率免伤，不是稳定减伤。
- 实战续航还受吸血、回血、击杀节奏影响，EHP 只是静态底盘。

### 3.3 经济模型（Materials/XP）

每波材料期望可抽象为：

```text
Mat_wave ~= Kills * DropChance(w) * DropMultiplier * AvgMatPerEnemy
           + Harvesting_wave
           + Crate/Recycle/GoldBonus
```

其中基础掉率衰减（核心刹车）：

```text
DropChance(w) = 1.0, w < 5
DropChance(w) = max(0.5, 1 - 0.015 * w), w >= 5
```

Harvesting 的复利特征（非 Endless）：

```text
Harvesting_{t+1} ~= ceil(Harvesting_t * 1.05), Harvesting_t > 0
```

经验升级门槛：

```text
XP_to_next(level) = (level + 3)^2
```

要点：

- 经济是“前宽后紧”的关键来源：掉率下降 + 通胀上升同时发生。
- XP 二次增长使“经验加成”存在自然边际递减。

### 3.4 商店模型（通胀与稀有度）

价格通胀核心口径：

```text
Price ~= floor((BasePrice + Wave + BasePrice * 0.1 * Wave) * ShopPriceFactor)
```

稀有度随波次+幸运上升（并有上限）：

- Tier2 最早 Wave2，Tier3 最早 Wave4，Tier4 最早 Wave8。
- 各 Tier 概率随波次增加，并受 Luck 放大，但存在最大概率上限。

要点：

- “能买得起”本身是被设计的稀缺资源。
- Lucky/经济流本质是提前获取高阶资源，而不是平白增加战力。

## 4. 把这套模型映射到 TeleTarot 的建议

### 4.1 建立 4 条可观测曲线

建议在你们的平衡日志里固定输出：

- `player_dps_curve(w)`
- `player_ehp_curve(w)`
- `enemy_pressure_curve(w)`（可用敌方总HP与总DPS近似）
- `economy_affordability_curve(w)`（每波可支配资源 / 商店均价）

只要这四条曲线稳定，角色和道具扩展就不容易把版本打崩。

### 4.2 推荐目标区间（用于联调）

可作为第一版经验阈值：

- 早期（1-6）：`affordability` 约 `1.1~1.4`（允许建立核心组件）
- 中期（7-14）：`0.9~1.2`（鼓励取舍）
- 后期（15-20）：`0.7~1.0`（强调路线完成度）

### 4.3 三类“防失控”保险丝

- 概率上限：闪避、暴击都要硬上限。
- 复利节流：对持续经济成长（如 Harvesting）设置阶段性衰减。
- 通胀联动：高稀有出现率提高时，同步抬升高稀有均价或机会成本。

---

## 5. 关键启发（可直接用于你们设计）

- 只加敌人强度不控经济，会让中后期变成“纯数值碾压失败”。
- 只加掉落和成长不控通胀，会让后期失去策略张力。
- 最稳定的做法是把“成长奖励”与“资源摩擦”同步升级。
