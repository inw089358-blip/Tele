## 1. 全局风格锚点

- 题材：`dreamcore + CRT glitch + retro electronic + cyber occult`
- 画风：`2D pixel-art, crisp clusters, high readability, game-ready`
- 配色：`deep navy base, controlled cyan signal glow, restrained warning red accents`
- 质感：`industrial worn material + ritual-tech ornaments`
- 背景规则：`transparent background (true alpha), no backdrop, no frame`
- 构图规则：`single item centered, full silhouette visible, no cropping`

## 2. 通用母提示词（模板）

```text
Single item game asset, 2D pixel-art, [item semantic], [rarity style], [build style], high readability silhouette, crisp pixel clusters, dreamcore CRT-glitch retro electronic tone, controlled cyan signal glow and restrained warning red accents, transparent background true alpha, centered composition, no cropping, no text, no logo, no watermark, no UI frame, production-ready icon/sprite
```

| rarity | visual style |
| --- | --- |
| common | minimal VFX, low glow intensity, silhouette-first readability |
| uncommon | subtle runes and material accents, gentle cold glow, clean contour priority |
| rare | distinct thematic feature, controlled aura glow, strong recognition point |
| epic | layered construction, visible energy textures, premium rare-material finish |
| legendary | iconic master silhouette, dominant symbolic motif, grand yet pixel-readable detailing |

- `prompt_main` = 资产类型 + 道具名语义 + 稀有度视觉层 + build主题词 + 生产约束
- `prompt_negative` = 全表统一模板，不做逐条改写
- `notes_cn` = 中文一句，强调本条视觉重点（轮廓/符号/材质/主题）
