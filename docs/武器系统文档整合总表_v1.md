## 3. 武器与奖励池映射（Chapter I）

### 3.1 奖励池结构（6大池）
1. 基础成长池：基础攻击/攻速/移速/拾取效率等稳定成长。
2. 武器行为池：穿透、分裂、追踪、爆炸、弹体寿命等攻击行为改造。
3. 生存反制池：护盾、减伤、受击恢复、低血保命。
4. 节奏资源池：体力恢复、位移消耗、技能冷却、击杀回能。
5. 经济运营池：经验倍率、金币倍率、补给站折扣。
6. 流派核心池：高收益高代价核心（如 glass_engine / fortress_cycle / tempo_overdrive）。

### 3.2 武器设计接入建议
- 武器基础体感优先由“基础成长池 + 武器行为池”驱动。
- 高风险武器（如流星锤、公路指示牌）默认绑定 1 条生存反制补偿路线。
- DOT武器（燃烧瓶）与多段武器（圆锯片、手里剑环）需限制吸血/触发频率，避免收益爆炸。

## 4. 角色与武器流派建议

### 4.1 愚者（广域命中/经济滚雪球）
- 推荐武器：苦无、链鞭、机械弩、手里剑环。
- 推荐词条：`attack_speed_up`、`pierce_plus`、`split_shot`、`pickup_radius_up`。
- 风险点：Boss前单体不足，需补 `boss_tag_damage`。

### 4.2 战车（机动换爆发/穿透清场）
- 推荐武器：钢筋矛、钉枪、公路指示牌、重型扳手。
- 推荐词条：`move_speed_up`、`skill_cd_down`、`tempo_overdrive`、`pierce_plus`。
- 风险点：站桩易断节奏，需要资源循环兜底。

### 4.3 倒吊人（低血收益/反制生存）
- 推荐武器：流星锤、燃烧瓶、圆锯片、钢管。
- 推荐词条：`damage_reduction_short`、`hit_recovery`、`lifesteal_light`、`boss_tag_damage`。
- 风险点：前期压血过度会连锁死亡。

### 4.4 力量（近距压制/受击收益）
- 推荐武器：公路指示牌、重型扳手、钢管、流星锤。
- 推荐词条：`max_hp_up`、`damage_reduction_short`、`hit_recovery`、`boss_tag_damage`。

### 4.5 节制（攻守双态/稳态运营）
- 推荐武器：机械弩、链鞭、鼓槌、信号弹。
- 推荐词条：`attack_speed_up`、`resource_cycle_up`、`cooldown_cut`、`shield_periodic`。

### 4.6 魔术师（技能循环/触发资源）
- 推荐武器：苦无、机械弩、链鞭、信号弹。
- 推荐词条：`attack_speed_up`、`pierce_plus`、`split_shot`、`cooldown_cut`。

## 5. 关卡推进中的武器构筑节奏（stage_001~005）

- `stage_001`：至少拿到 1 生存 + 1 输出，避免开局崩盘。
- `stage_002`：开始补武器行为（穿透/分裂/追踪）提升清图效率。
- `stage_003`：补单体有效项，为 Boss 前压血做准备。
- `stage_004`：输出与生存保持平衡，不建议纯经济贪心。
- `stage_005`：至少满足“2输出 + 1生存”再考虑核心池。

## 6. 属性与数值口径（武器相关）

### 6.1 关键扩展属性（提案）
- `attack_speed_mult`
- `crit_chance`
- `crit_multiplier`
- `lifesteal`
- `armor`
- `dodge_chance`

### 6.2 武器平衡约束建议
- 暴击率、闪避率设置硬上限，防止后期失控。
- 多段命中类武器需加吸血触发频率上限。
- 输出乘区拆分：攻击强度、攻速、命中形态分开结算。

## 7. 落地优先级（文档到实装）

1. 首批实装建议（5个）：苦无、公路指示牌、圆锯片、燃烧瓶、机械弩。
2. 每个武器先补齐最小数据：攻击模式、成长曲线、稀有度、升级词条。
3. 武器行为池先接 `pierce_plus / split_shot / blast_on_hit` 三类核心行为。
4. 完成后进行 Chapter I 回归：`stage_001~005` + Boss-1。
