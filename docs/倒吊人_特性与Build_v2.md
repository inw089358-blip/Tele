## 1. 低数值规则说明
- Lv1 基线：`HP 7 / 基础伤害 8`。
- 低血收益角色，必须先确保可控生存窗口。

## 2. 角色定位与风险画像
- 定位：低血收益控制 + 风险换上限 + 反制生存。
- 强势期：中后期。
- 失败点：前期压血过度导致连锁死亡。

## 3. Build 路线（4条）

### 3.1 稳定主线 Build（推荐）
- 核心：`max_hp_up`、`shield_periodic`、`hit_recovery`
- 目标区间：生存 `+25%~+55%`，输出 `+20%~+40%`
- 早期策略：先保命再输出。

### 3.2 高风险高回报 Build
- 核心：`glass_engine`、`lifesteal_light`、`boss_tag_damage`
- 目标区间：输出 `+45%~+70%`
- 风险提示：需至少 1 条恢复链路。

### 3.3 生存反制 Build
- 核心：`damage_reduction_short`、`shield_periodic`、`control_resist`
- 目标区间：生存 `+35%~+80%`
- 风险提示：纯防御会导致清怪慢。

### 3.4 Boss-1 定向 Build
- 核心：`boss_tag_damage`、`skill_cd_down`、`hit_recovery`
- 前提：采用 v2.1 敌方伤害下调口径。
- 目标区间：输出 `+35%~+55%` + 生存 `+25%~+55%`

## 4. 关卡阶段打法（stage_001~005）
- `stage_001`：先确保不暴毙。
- `stage_002`：建立控场节奏。
- `stage_003`：补恢复续航。
- `stage_004`：宁稳不贪。
- `stage_005`：P2/P3 以存活优先。

## 5. 可落地参数锚点（文档）
- 角色 Lv1：`HP 7 / 伤害 8`
- 敌方建议：普通接触1，远程/精英2，Boss接触2~3；普通子弹1，精英/Boss子弹2。

## 6. 脚本映射
- 现有字段：`max_hp`、`bonus_attack_damage`、`move_speed`、`stamina_*`。
- 待扩展：低血阶段标签、吸血、控制抗性。

## 7. MVP 落地顺序（文档级）
1. 先上稳定主线奖励链。
2. 再上生存反制与低血控制。
3. 最后上高风险上限分支。
