# 👾 二、敌人设计 (Enemies)

### 【敌01】故障史莱姆 (Glitch Blob)

```
PROMPT: Enemy sprite design - "Glitch Blob" for Tarot Dreamscape
TYPE: Basic enemy, top-down 2D pixel art sprite
ROLE: First enemy players encounter, slow melee, splits on death

DESCRIPTION:
An amorphous blob creature made of corrupted data and visual artifacts:
- Irregular blob shape, roughly circular but with jagged/uneven edges
- Body composed of shifting pixel clusters in wrong colors
- Surface shows horizontal tear lines and displacement glitches
- Single or pair of simple "eyes" that are just bright squares/dots 
  (sometimes misaligned, one higher than other)
- Color palette shifts subtly between frames (RGB jitter)
- Leaves faint trail of static noise when moving
- Small size, clearly "weak" enemy silhouette
- Occasional frame where appearance briefly "corrupts" into scrambled pixels

COLOR VARIATIONS:
- Base body: Muted teal/green (#2d5a4a) with magenta glitch patches (#ff006e)
- Eyes: Bright cyan (#00ffff) or signal green (#00ff41)
- Glitch accents: Random hot pixels in red (#ff0040), purple (#b967ff)
- Outline: Dark (#0a1628), 1px

ANIMATION FRAMES:
1. Idle (3 frames): Pulsing/breathing size change, colors shimmering
2. Move (4 frames): Wobbly rolling motion, slight shape deformation
3. Attack (2 frames): Brief lunge expansion, contact flash
4. Death/Split (6 frames): Body stretches → tears apart → becomes 2 smaller blobs
   (smaller blob version needed for split spawn)
5. Mini-blob variant (for post-split): Same but 50% size, slightly faster animation

TECHNICAL SPECS:
- Size: 24×24px base (small enemy)
- Sprite sheet format, grid-aligned white background
- Must have "split" offspring version at 12×12px
- Simple enough for 200+ on screen without performance issues
- Clear hitbox indication (roughly circular)

DIFFICULTY CUE: Cute-but-wrong aesthetic, non-threatening shape, 
slow movement telegraphs low danger level
```

### 【敌02】静电精灵 (Static Sprite)

```
PROMPT: Enemy sprite design - "Static Sprite" for Tarot Dreamscape
TYPE: Ranged enemy, top-down 2D pixel art
ROLE: Mid-tier enemy, shoots slow projectiles from distance

DESCRIPTION:
A humanoid figure composed of television static and interference patterns:
- Roughly humanoid silhouette but edges are fuzzy/noisy (like poor reception)
- Body filled with animated static grain texture (black/white/gray noise)
- Occasional moments of "clarity" where a vague face or form is visible
  then dissolves back to static
- Faint CRT scanlines visible across body
- One arm extended forward (shooting posture hint)
- Floating/drifting movement style (no legs visible, or legs are static-noise)
- Size between blob and stalker
- Emits small spark particles periodically

COLOR PALETTE:
- Body base: Grayscale noise (random #000000 to #ffffff pixels)
- Accent flashes: Cyan (#00ffff) or magenta (#ff006e) electrical arcs on surface
- Eye area: Briefly visible as bright spot (#00ff41)
- Outline: Not solid, instead has "interference border" effect
- Projectile it fires: Small glowing pixel orb

ANIMATION FRAMES:
1. Idle (4 frames): Static pattern changing each frame (noise animation)
2. Move (4 frames): Drifting, static intensity increases
3. Attack (4 frames): Arm extends → charge glow → projectile releases → recoil
4. Hit (2 frames): Static bursts outward briefly, color inversion flash
5. Death (5 frames): Signal lost effect - vertical hold collapse, 
   shrinking to single point then disappearing

TECHNICAL SPECS:
- Size: 28×28px base
- Static texture should be actual noise (not hand-drawn random, use procedural or 
  pre-generated noise sprites)
- Projectile sprite also needed: 8×8px glowing orb
- Medium complexity, clear humanoid readable shape

SPECIAL NOTE: This enemy's core gimmick is the static/noise visual - 
it should look like a TV channel that can't quite tune in properly
```

### 【敌03】像素潜行者 (Pixel Stalker)

```
PROMPT: Enemy sprite design - "Pixel Stalker" for Tarot Dreamscape
TYPE: Fast ambush enemy, top-down 2D pixel art
ROLE: High-speed threat, dashes at player, stealth elements

DESCRIPTION:
A sleek, predatory entity made of sharp pixel geometry:
- Elongated, angular shape suggesting speed (horizontal orientation when moving)
- Composed of sharp-edged pixel triangles and lines (low-poly aesthetic)
- Dark body with bright edge highlighting (suggests sleekness)
- "Face" is just a slit or narrow glowing line (predator eyes feel)
- When idle: partially transparent/faded (stealthed state hint)
- When dashing: Stretched horizontally with motion line afterimage
- Leaves brief afterimage trail (previous position ghost)
- Most visually "dangerous" looking of basic enemies

COLOR PALETTE:
- Body: Very dark near-black (#0d1524) with dark blue undertone
- Edges/highlights: Sharp cyan (#00ffff) or white (#e0e6ed) accent lines
- Eye-slit: Intense red (#ff0040) or amber (#ffaa00)
- Afterimage: Faded copy at 30% opacity
- Dash trail: Horizontal pixel streaks in accent color

ANIMATION FRAMES:
1. Idle/Stealth (4 frames): Very subtle breathing, partial transparency,
   occasional flicker
2. Move (4 frames): Quick stride-like motion blur hints
3. Dash/Charge (3 frames): Extreme stretch, afterimage frames needed
4. Attack/Lunge (4 frames): Strike motion, claw/edge extension
5. Hit (3 frames): Brief visibility forced (lose stealth), flash red
6. Death (4 frames): Shattering into geometric fragments, triangle pieces flying

TECHNICAL SPECS:
- Size: 32×32px base (slightly larger due to elongated shape)
- Must include transparency/alpha support for stealth state
- Afterimage frames should be separate or built into animation
- Sharp, aggressive silhouette - instantly recognizable as threat

VISUAL IDENTITY: The "assassin/ninja" of the enemy roster - 
should feel fast, dangerous, and unsettling
```

### 【敌04】数据腐蚀者 (Data Corrupter)

```
PROMPT: Enemy sprite design - "Data Corrupter" for Tarot Dreamscape
TYPE: Debuff/support enemy, top-down 2D pixel art
ROLE: Slows player, medium threat, area effect presence

DESCRIPTION:
A larger, heavier enemy that looks like corrupted file/data:
- Bulkier than basic enemies, roughly square/blocky shape
- Body looks like damaged code or broken image file rendered as creature
- Visible "error" symbols on body: X marks, warning triangles, 
  garbled text characters scattered on surface
- Antenna-like protrusions on top emitting corruption waves
- Slow, heavy movement (visual weight important)
- Pulse effect: periodic ring expansion from center (attack range indicator)
- Looks like it's "infecting" the space around it

COLOR PALETTE:
- Body: Sickly green-yellow (#4a6b32) mixed with error-red (#ff0040) patches
- Error markings: Bright red (#ff0040) or amber (#ffaa00) 
- Corruption field: Faint purple (#b967ff) translucent aura/rings
- Antenna tips: Pulsing magenta (#ff006e)
- Text/garbage on body: Various off-colors, deliberately "wrong" looking pixels
- Outline: Thick dark (#0a1628), 2px for weight feel

ANIMATION FRAMES:
1. Idle (4 frames): Heavy bobbing, corruption pulse expanding/contracting
2. Move (3 frames): Slow deliberate steps, screen-shake adjacent hint
3. Attack/Corrupt (4 frames): Antenna pulse intensifies, ring expands outward
4. Hit (3 frames): Error symbols flash brighter, body jerks
5. Death (7 phases): Data deletion animation - fragmentation, 
   blue-screen-of-death style crash effect, dissolve

TECHNICAL SPECS:
- Size: 40×40px (larger enemy, mini-boss feel among regulars)
- Corruption aura could be separate overlay sprite
- Error text/symbols should be readable-ish as "glitched language"
- Heavy visual presence - should stand out from weaker enemies

SPECIAL MECHANIC VISUAL: The slow aura/pulse should be clearly 
visible so players understand the danger zone
```

### 【敌05】信号干扰者 (Signal Jammer)

```
PROMPT: Enemy sprite design - "Signal Jammer" for Tarot Dreamscape
TYPE: Disruptor enemy, top-down 2D pixel art
ROLE: Temporarily disrupts player auto-aim, annoyance/tactical threat

DESCRIPTION:
A chaotic, noisy entity that embodies signal interference:
- Central core (eye or crystal) surrounded by orbiting debris/particles
- Asymmetric, messy silhouette (deliberately "wrong" looking)
- Multiple small elements floating around main body (satellite dish shapes, 
  antenna fragments, wave symbols)
- Constantly emitting visual "noise" - stray pixels, small particles drifting off
- Looks like it's broadcasting interference
- Slightly erratic movement suggested by wobbly animation
- Disorienting to look at (achieved through asymmetric design)

COLOR PALETTE:
- Core: Bright intense color (choice of #00ff41 or #ff0040) - focal point
- Body: Muted gray-blue (#4a5568) with heavy noise texture
- Orbiting parts: Mixed colors (cyan, magenta, amber - all muted)
- Noise particles: Random colored 1-2px dots drifting away
- Interference waves: Subtle concentric rings (barely visible, 
  like heat shimmer but digital)

ANIMATION FRAMES:
1. Idle (6+ frames): Orbiting parts rotating, particles spawning and fading,
   core pulsing - BUSY animation
2. Move (4 frames): Wobbly drift, orbiting parts wobble too
3. Attack/Jam (4 parts): Core flares, intense particle burst, 
   screen-edge vignette flash suggestion
4. Hit (3 frames): Orbiting parts scatter momentarily, core flickers
5. Death (6 frames): Core overloads, orbiting parts fly off, 
   final burst of static then silence

TECHNICAL SPECS:
- Size: 32×32px core + ~16px orbit radius (effective 48×48px presence)
- Particle effects may need separate sprite layer
- Animation should feel chaotic but not unreadable
- More frames than average enemy due to busy nature

DESIGN PHILOSOPHY: Visual noise made manifest - 
this enemy should be slightly annoying to even LOOK at, 
mirroring its gameplay effect
```
