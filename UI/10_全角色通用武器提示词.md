# ⚔️ 十、全角色通用武器提示词 (Shared Weapons Prompts)

> 适用：愚者 / 战车 / 倒吊人均可使用的“通用武器”美术出图  
> 风格对齐：`dreamcore + CRT glitch + pixel-art`，Top-down 2D  
> 建议用途：武器立绘、武器卡牌图、战斗内掉落图标、商店展示图

---

## 0. 通用母提示词（每条武器都建议拼接）

```text
Top-down 2D pixel-art weapon asset for a dreamcore glitch roguelite shooter, retro CRT sci-fi fantasy style, clean silhouette, high gameplay readability, deep navy and teal base palette with signal green and warning red accents, transparent background, no text, no logo, no watermark
```

## 0.1 通用负面提示词

```text
no realistic photo style, no side view perspective, no isometric perspective, no blurry edges, no over-detail noise, no UI frame, no text label, no watermark, no logo, no signature, no background scene
```

## 0.2 建议规格

- 武器图标：`256x256`（源图）-> 下采样到 `64x64`
- 武器展示卡：`512x512` 或 `768x768`
- 透明底：`PNG with alpha`
- 单图颜色控制：建议 `12-20` 主色阶，避免脏色

## 3. 备注（与当前项目保持一致）

- 本文档定义的是“全角色可共用”武器视觉层，不绑定角色专属机制。
- 若后续要落到数值与掉落池，可与 `weapon_behavior` 类奖励条目（多重、穿透、追踪、爆炸等）一一映射。
- CRT 效果优先由引擎后处理叠加，避免武器源图烘焙过重扫描线。
