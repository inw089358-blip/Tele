# 🗺️ 五、背景与场景 (Backgrounds & Stages)

### 【场景01】第0关 - 教程关 / 梦境入口

```
PROMPT: Stage background - "Tutorial/Dream Entrance" for Tarot Dreamscape
TYPE: Seamless looping background, top-down 2D, parallax capable
THEME: First steps into the dream, gentle introduction, learning space

VISUAL CONCEPT:
The gentlest environment - a liminal space between waking and dreaming.
Like the moment when you're falling asleep and see abstract shapes behind 
your eyelids. Should feel safe but otherworldly.

BACKGROUND LAYERS (back to front):

┌─────────────────────────────────────────────────────┐
│ LAYER 0: Deep background (slowest parallax)         │
│ ─────────────────────────────────────────────────── │
│ Color: #080d18 (near-black with blue undertone)     │
│ Elements:                                           │
│   · Extremely faint star-like pixels (1-2px)        │
│   · Very slow drift in random directions            │
│   · Occasional "shooting star" streak (rare)       │
│   · Density: ~50 dots across full 1920×1080         │
│ Animation speed: 0.1x (barely moving)               │
│                                                      │
│ LAYER 1: Mid-background                             │
│ ─────────────────────────────────────────────────── │
│ Color: #0a1628 to #0d1a2d gradient (subtle)        │
│ Elements:                                           │
│   · Abstract geometric shapes floating              │
│   · Faint wireframe grid pattern (like 3D space)    │
│     visible at ~15% opacity                         │
│   · Large soft circles/orbs (bokeh effect)          │
│     in muted purple/blue, drifting slowly           │
│   · Subtle horizontal scan lines at 3% opacity      │
│ Animation speed: 0.3x                               │
│                                                      │
│ LAYER 2: Foreground details                          │
│ ─────────────────────────────────────────────────── │
│ Color: Base #111d35                                  │
│ Elements:                                           │
│   · Larger geometric shapes (triangles, hexagons)    │
│     outlined in #2d3f5c, filled with #111d3560      │
│   · Faint "floor" grid suggesting ground plane      │
│   · Scattered tarot card symbols (very faded)        │
│     floating/rotating slowly                        │
│   · Occasional glitch artifact: single frame of      │
│     displaced pixels (once every 5-8 seconds)       │
│ Animation speed: 0.5x                               │
│                                                      │
│ INTERACTION LAYER (gameplay surface):                │
│ ─────────────────────────────────────────────────── │
│ Color: #0a1628 (matches spec base color)             │
│ Treatment: Mostly clear, subtle texture overlay      │
│   · Very faint noise texture (2% opacity)           │
│   · No obstacles or cover (tutorial = open space)    │
│   · Soft edge darkening (vignette start)            │
│                                                      │
│ ATMOSPHERE EFFECTS:                                  │
│ · Overall brightness: Low but not dark              │
│ · Mood: Calm, mysterious, inviting                  │
│ · Color temperature: Cool blue, slight purple tint   │
│ · No threatening elements                           │
│ · CRT effects applied via shader (not baked-in)     │
└─────────────────────────────────────────────────────┘

TILE/SEAMLESS SPECS:
- Format: Can be tiled horizontally for extended play areas
- Recommended size: 2048×2048px source (allows panning)
- Or: Layered PNGs for parallax implementation
- Edge blending: Seamless wrap on all layers except maybe layer 0

MOOD REFERENCE:
· The void between levels in Yume Nikki
· Windows 95 "flying through space" screensaver but darker
· Opening sequence of Serial Experiments Lain
· That feeling of lying in bed, eyes closed, seeing colors
```

### 【场景02】第1关 - 虚幻前庭 (Illusory Vestibule)

```
PROMPT: Stage background - "Illusory Vestibule" (Stage 1)
TYPE: Battle stage background, top-down 2D, seamless
DIFFICULTY: Easy | THEME: Entry-level challenge area
COLOR: #0a1628 (base)

CONCEPT:
A vast empty hall that feels like an abandoned digital lobby.
Like a loading screen that became a place. Faint traces of 
structure suggest this was once something organized.

LAYER COMPOSITION:

┌─────────────────────────────────────────────────────┐
│ BACKGROUND DEPTH: 4 layers + interaction surface     │
│                                                      │
│ LAYER 0 - THE VOID (parallax 0.1x):                 │
│ · Near-pure black-blue (#060a12)                    │
│ · Distant "pillars" or "towers" as silhouettes      │
│   - Height: 200-400px, width: 20-40px              │
│   - Spaced irregularly, fading into distance        │
│   - Suggest infinite corridor or hall               │
│ · Very faint fog/mist effect (gradient fade)        │
│                                                      │
│ LAYER 1 - STRUCTURE (parallax 0.3x):                │
│ · Floor/grid pattern becoming visible               │
│ · Perspective grid lines converging to center/horizon│
│   - Color: #1a274430 (very subtle)                 │
│   - Suggests large open space                       │
│ · Wall-like elements at edges                       │
│   - Vertical lines suggesting boundaries            │
│   - Height varies, creating rhythm                  │
│ · Occasional "doorway" or "portal" shapes           │
│   - Just outlines, dark frames                      │
│   - Lead nowhere (false depth)                      │
│                                                      │
│ LAYER 2 - DETAILS (parallax 0.6x):                  │
│ · Floor texture: Subtle tile pattern                 │
│   - Each tile: 64×64px conceptual size              │
│   - Color variation: ±5% brightness per tile        │
│   - Some tiles slightly "corrupted" (wrong color)   │
│ · Scattered debris/objects:                         │
│   - Small pixel clusters (rubble?)                  │
│   - Faint glowing spots (pickup locations hint)     │
│   - Random static patches                           │
│ · Edge definition: Walls become more solid          │
│   - Left/right borders darker                       │
│   - Suggest arena boundary                          │
│                                                      │
│ LAYER 3 - FOREGROUND (parallax 0.9x):               │
│ · Close-up floor details                            │
│   - Larger tile patterns, more defined              │
│   - Slight texture/noise                            │
│ · Corner elements (frame the view):                 │
│   - Top-left: Abstract architectural fragment       │
│   - Bottom-right: Similar fragment                  │
│   - Create sense of looking through opening         │
│ · Occasional foreground "glitch object":            │
│   - Floating wrong-colored pixels near edges        │
│   - Adds to unease without blocking gameplay        │
│                                                      │
│ GAMEPLAY SURFACE:                                   │
│ · Clean #0a1628 base                                │
│ · Subtle grid overlay at 8% opacity for orientation │
│ · No collision objects drawn (handled separately)   │
│                                                      │
│ SPECIAL ELEMENTS FOR STAGE 1:                       │
│ · "Tutorial hints" as environmental storytelling:   │
│   - Faint arrow shapes on floor (barely visible)    │
│   - Slightly brighter path suggesting direction      │
│   - All very subtle, not hand-holding               │
│                                                      │
│ WAVE TRANSITIONS (visual changes per wave):          │
│ Wave 1 (苏醒): Normal state, calm                   │
│ Wave 2 (杂音): Slight static increase, edges darken │
│ Wave 3 (共振): Grid becomes more visible,           │
│             occasional color flashes in bg          │
│ Boss: Heavy vignette, red tint at edges, intense    │
└─────────────────────────────────────────────────────┘

TECHNICAL NOTES:
- Total layer count: 4 parallax + 1 surface = 5 images
- Each layer should be 2560×1440 (oversized for camera pan)
- Or: Procedural generation acceptable for repeating patterns
- Memory target: <50MB total for all stage backgrounds
```

### 【场景03】第4关 - 破碎的显示器 (Broken Monitor) - BOSS关

```
PROMPT: Boss stage background - "Broken Monitor" (Stage 4, Convergence Point)
TYPE: Dramatic boss arena background, high visual intensity
THEME: System failure, critical error, the breaking point

CONCEPT:
The battlefield looks like the inside of a dying monitor or a 
corrupted video feed reaching its limit. This is where the 
Dream Watcher resides - the point where dreams are monitored 
and sometimes... terminated.

This should be the most visually intense standard stage.
Not chaotic to the point of unreadable, but clearly WRONG.

┌─────────────────────────────────────────────────────────┐
│                                                          │
│  ╔═════════════════════════════════════════════════╗    │
│  ║     VISUAL INTENSITY: HIGH (7/10)                ║    │
│  ║     GLITCH FREQUENCY: ELEVATED                    ║    │
│  ║     COLOR INSTABILITY: PRESENT                    ║    │
│  ╚═════════════════════════════════════════════════╝    │
│                                                          │
│  LAYER 0 - CORRUPTED DEPTH:                            │
│  · Background shows signs of severe corruption          │
│  · Instead of clean gradient: color banding/errors      │
│  · Horizontal tear lines across entire layer            │
│    (static tears, not animated - part of image)        │
│  · Color shifts: Left side cooler, right side warmer    │
│    (suggesting signal degradation)                     │
│  · Large "dead pixel" areas: solid color blocks         │
│    scattered in deep background                        │
│                                                          │
│  LAYER 1 - BROKEN STRUCTURE:                           │
│  · The "hall" from previous stages is now damaged      │
│  · Walls have cracks (literal visual cracks)            │
│    rendered as jagged dark lines                       │
│  · Grid pattern is broken: offset sections, gaps       │
│  · Some areas show "underlying layers" like peeling     │
│    (different pattern showing through cracks)          │
│  · Debris particles frozen in air (suspended animation) │
│                                                          │
│  LAYER 2 - ACTIVE CORRUPTION:                          │
│  · This layer has MORE going on than usual              │
│  · Static noise patches: scattered rectangular areas    │
│    of pure TV static (animated if possible)            │
│  · Color bleeding: areas where red/green/blue channels  │
│    are visibly separated (chromatic aberration zones)  │
│  · "Error text": Scattered garbled characters in       │
│    corners and edges (decorative, like: █▓▒░ ░▒▓█)   │
│  · Warning indicators: Faint amber/red flashing        │
│    zones (suggest danger areas)                        │
│                                                          │
│  LAYER 3 - FOREGROUND CHAOS:                           │
│  · Heaviest detail layer yet                            │
│  · Screen-edge damage simulation:                      │
│    - Darkened/burned-looking edges                     │
│    - Vignette built into layer (stronger than usual)   │
│    - Corner artifacts (test-pattern-like elements)     │
│  · Floating debris: Pixel fragments, small geometric   │
│    pieces drifting slowly                              │
│  · Scanlines more prominent (visible at 10-15%)        │
│  · Occasional "frame drop" suggestion: duplicated      │
│    or offset horizontal strips                         │
│                                                          │
│  ARENA CENTER (BOSS SPAWN POINT):                      │
│  · Circular platform or marking                        │
│  · Glowing ring pattern (suggests ritual/summoning)    │
│  · Colors pulse slowly: purple → red → purple          │
│  · Concentric circles with data/tech symbols between   │
│  · This is where Dream Watcher materializes            │
│                                                          │
│  PHASE-BASED VISUAL CHANGES (sync with boss phases):   │
│  ────────────────────────────────────────               │
│                                                          │
│  PHASE 1 (100%-66% HP):                                 │
│  · Current description = baseline                      │
│  · Intense but manageable                              │
│  · Boss eye visible in center                          │
│                                                          │
│  PHASE 2 (65%-33% HP):                                 │
│  · ADDITIONAL: Red warning light sweeping across       │
│  · Static noise frequency increases                    │
│  · More tears/cracks appear (can be overlaid)          │
│  · Background color shifts toward warmer (danger)      │
│  · New: Data stream particles flowing upward           │
│                                                          │
│  PHASE 3 (32%-0% HP):                                  │
│  · CRITICAL: Maximum visual distress                   │
│  · Heavy RGB separation globally                       │
│  · Frequent flash-white moments (screen-wide)          │
│  · Debris particles increase in number                 │
│  · Edges develop red tint (blood/violence metaphor)    │
│  · Countdown numbers may appear in background          │
│  · Everything feels like it's about to BREAK           │
│                                                          │
│  POST-BOSS (VICTORY):                                  │
│  · Sudden calm: All chaos stops                        │
│  · Fade to cleaner state (reward transition)           │
│  · Remaining: Gentle glow, victory atmosphere          │
│  · Contrast makes relief feel earned                   │
│                                                          │
└─────────────────────────────────────────────────────────┘

COLOR PALETTE SHIFT (across fight):
Start:  #0a1628 (normal deep blue)
Phase 2: #1a1028 (warm dark, red creeping in)
Phase 3: #1a0818 (heavy red-purple tint)
Victory: #0a1828 (slightly lighter, relieved)

SPECIAL TECHNICAL NOTE:
This stage benefits from DYNAMIC/MODIFIABLE layers.
Consider implementing some effects (noise, tears, color shift)
as real-time overlays rather than baked into static images,
allowing smooth transitions between phases.
```
