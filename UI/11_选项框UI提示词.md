# 🧩 十一、选项框 UI 提示词 (Option Box UI Prompts)

> 适用：主菜单选项、奖励三选一卡片、设置页选项框、商店交互选项  
> 风格对齐：`Dreamcore Glitch + CRT`，与现有 UI 规范统一  
> 输出目标：可直接用于 AI 出图或外包美术制作

---

## 1. 设计目标

- 强调“可读性优先”：一眼看出是否可选、已选、不可选
- 视觉语言统一：深空蓝底 + 信号绿高亮 + 干扰红警示
- 组件可复用：同一套选项框可覆盖菜单、奖励、设置、商店

---

## 2. 通用母提示词（核心）

```text
Futuristic CRT-glitch option box UI component for a 2D roguelite game, pixel-art inspired but clean modern game UI, deep navy panel background, sharp-corner rectangular frame, readable text area, subtle scanline texture, controlled glitch accents, high contrast, game-ready UI asset, no logo, no watermark
```

---

## 3. 负面提示词（必须带）

```text
no realistic photo style, no soft rounded mobile UI, no heavy bloom, no over-complex ornaments, no unreadable neon overload, no perspective distortion, no watermark, no logo, no unrelated background scene
```

---

## 4. 组件结构提示词

```text
Option box structure: rectangular frame with title area, value area, optional description line, optional icon slot on the left, rarity/status tag on the bottom-right, clear border hierarchy, center-aligned readable content, transparent background around the component
```

---

## 5. 状态分版提示词

### 5.1 默认态 Default

```text
Default option box state, dark navy semi-transparent panel (#1a2744cc), 1px border (#2d3f5c), primary text (#e0e6ed), secondary text (#8b9bb4), low-intensity noise texture, stable and neutral
```

### 5.2 悬停态 Hover

```text
Hover option box state, brighter panel (#243656dd), 2px signal-green border (#00ff41) with subtle outer glow, title text slightly brighter, left edge horizontal glitch tear accent, interactive and responsive
```

### 5.3 选中态 Selected

```text
Selected option box state, emphasized frame with double border (inner #00ff41, outer #00ffff), active pulse highlight, value text in signal green, clear selected marker on top-right corner, strong confirmation feel
```

### 5.4 禁用态 Disabled

```text
Disabled option box state, darker panel (#0d152480), muted text (#4a5568), faint border (#1a2744), static-noise fill pattern, no glow, clearly unavailable but still readable
```

### 5.5 警告态 Danger/Costly

```text
Danger option box state, dark panel with restrained red accents (#ff0040), warning stripe details on corners, value/cost area highlighted in amber-red, high readability without aggressive flashing
```

## 7. 尺寸建议

- 菜单选项框：`320x56`
- 设置行选项框：`560x64`
- 奖励选项卡：`280x420`
- 商店选项框：`420x120`
- 导出建议：`2x` 源尺寸绘制后再缩放，保证边缘清晰

## 9. 落地备注

- CRT 扫描线、闪烁、色散建议在引擎后处理叠加，不要在组件源图烘焙过重。
- 选项框边框尽量保持直角和轻微不对称，维持项目“故障电子设备”气质。
- 同屏多个选项框时，最多只允许一个高亮主焦点，避免视觉冲突。
